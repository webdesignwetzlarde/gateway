# Support

Kopist is a volunteer-run open-source project in its design phase. There is no commercial support
and no service-level agreement.

| Need | Where |
|---|---|
| Question or idea | GitHub Discussions (once enabled) or an issue |
| Bug report | Issue with the "bug report" template |
| Design proposal | Issue with the "design proposal" template |
| New attack technique for the corpus | Issue with the "attack technique" template |
| Security vulnerability | [SECURITY.md](SECURITY.md), never a public issue |
